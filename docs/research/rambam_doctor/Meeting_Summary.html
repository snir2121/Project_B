Project Requirements: AI Holter Monitor Analyzer

Project Goal: Develop an automated AI-based system to analyze 24-hour multi-lead Holter ECG recordings to prevent Sudden Cardiac Death (SCD) in the young.

Target Pathologies: Brugada Syndrome (Type 1) and Congenital Long QT Syndrome.

1. Brugada Syndrome (Type 1) Detection

Target Leads (Input)

  • Standard Placement: Analyze leads V1, V2, and V3.
  • High Lead (HL) Placement: If metadata indicates High Leads, also analyze V5 and V6.

Detection Logic (Heuristics)

The AI must identify a "Coved" ST-segment elevation. A positive detection requires both of the following conditions:

  1. Amplitude Threshold: The J-point peak amplitude must be > 0.2 mV (Visual equivalent: higher than 2 small ECG squares).
  2. Morphology Shape: There must be a monotonic downward slope from the J-point to the T-wave point.

2. Long QT Syndrome Detection

Target Leads (Input)

Analysis is performed across all 12 leads.

Filter Rule: The Stability Check

Before calculating QT intervals, the signal must be filtered for heart rate stability:

  • Condition: If the heart rate changes by more than 10 BPM within 1 minute, the segment is considered unstable.
  • Action: Discard segment. Do not calculate QT for this window.

Measurement Thresholds

We measure the absolute QT interval from the onset of the Q-wave to the end of the T-wave. We then normalize this value using Bazett's Formula (QTc = QT / square root of RR):

  • Men: Abnormal if QTc > 440 ms.
  • Women: Abnormal if QTc > 460 ms.

Note: System must ingest patient gender as metadata.

3. System Output & Scoring

The system does not provide a binary "Sick/Healthy" result. It calculates the burden of the disease over the 24-hour recording.

Primary Metrics

  • Presence: Is the phenomenon detected? (Yes/No)
  • Burden: What percentage of the valid 24-hour recording contains the pattern?

Final Score (1-3 Scale)

Score Meaning Clinical Implication
1 Normal Phenomena absent or negligible.
2 Intermediate / Monitoring Phenomena present but low burden/frequency.
3 Treatment Required Phenomena appear frequently/high burden.
