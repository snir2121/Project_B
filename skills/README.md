# Project Skills

This folder contains project-specific skills, workflows, and instructions.

Files in this folder are shared through Git and can be edited by project collaborators and coding agents. Add each skill as a separate Markdown file with a clear name and purpose.

- `general_project_info.md`: Project context, repository organization, collaborators, and Git workflow.
- `todo_and_planning.md`: Shared format and rules for TODO and Done task lists.
